Station Name In Roster Plugin

📌 Proposta do Plugin (O que ele faz?)

Em ambientes corporativos de saúde e administrativo, gerenciar a localização física dos operadores é um desafio constante para as equipes de suporte de TI. Este plugin foi desenvolvido para resolver essa dor de forma totalmente automatizada e transparente.

Ele rastreia em tempo real qual computador físico cada funcionário está utilizando e exibe o nome da estação de trabalho diretamente na lista de contatos (Roster) do Spark para toda a organização.

⚙️ Como o Script Funciona?

  • Interceptação Server-Side: O plugin atua diretamente no núcleo do servidor Openfire. Ele monitora a rede continuamente aguardando a troca de status dos usuários.
  • Captura do Hostname (Resource): No momento em que um usuário faz login ou altera seu estado, o plugin captura o "Resource" da sessão XMPP, que o aplicativo Spark preenche de forma nativa com o nome de rede da máquina Windows.
  • Injeção Dinâmica: O script modifica temporariamente a mensagem de presença em memória, inserindo o nome do computador no final do status atual do usuário.
  • Compatibilidade de Estados: A regra é aplicada de forma abrangente para os estados Disponível (Online), Ausente (Away) e Não Perturbe (DND).
  • Preservação de Dados: Caso o usuário utilize um status customizado (como a indicação de seu ramal ou subsetor), o plugin preserva essa informação intacta e apenas concatena o nome do computador ao final da frase.

💡 Principais Benefícios

  • Rastreabilidade Imediata: Localize qualquer funcionário fisicamente na clínica apenas olhando para a lista do Spark, agilizando atendimentos remotos e presenciais.
  • Impacto Zero no Cliente: O processamento é feito inteiramente no servidor. Não requer nenhuma configuração, instalação ou atualização nas máquinas dos usuários finais.
